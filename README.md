# Cerces

一个手机端优先、可静态部署的本地刷题工具。支持单选、多选和大题，支持 Excel、Word、PDF 题库导入，以及直接显示答案的提示功能。

当前视觉版本采用“Liquid Obsidian”方向：深色玻璃层、冷色低光、细微颗粒、粗圆头进度环和弹簧式状态反馈。

主题默认跟随手机系统：

- 深色模式使用暗色低光玻璃。
- 浅色模式使用带可见环境色晕的亮色玻璃，并保持同一层级和动画节奏。
- 首页可以手动切换深浅主题，选择会保存在当前浏览器。

旧版手机原生风已经留档：

- `archive/mobile-native-v1/`
- 留档说明：`archive/mobile-native-v1/ARCHIVE.md`

## 功能

- 单选和多选自动判分。
- 大题对照参考答案后自评：掌握、部分掌握、未掌握。
- 支持解析带文字层且包含答案区的 PDF 题库。
- 导入时自动排除文件内重复题和已有题库中的重复题。
- 每题可一键查看正确答案；导入的“提示”字段作为补充提示显示。
- 顺序练习、随机练习和错题巩固。
- 练习范围可选全部题目、选择题或填空 / 大题。
- 自动记录正确率、待巩固题目和提示使用次数。
- 题库、练习进度和备份保存在浏览器 IndexedDB 中。
- JSON 数据备份与恢复，题库可导出为 Excel。
- 手机端优先，支持 iPhone 和 Android 浏览器。
- 可安装为 PWA；首次打开后缓存应用资源。
- 支持系统“减少动态效果”设置。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开终端中显示的本地地址。

## 构建与部署

```bash
npm run build
```

构建结果位于 `dist/`。将 `dist/` 上传到任意静态站点即可，例如 Cloudflare Pages、Vercel、Netlify、GitHub Pages 或普通静态服务器。

Vite 已设置相对资源路径，因此也支持部署到域名下的子目录。

## 安装到手机

- iPhone：使用 Safari 打开部署地址，点击分享，再选择“添加到主屏幕”。
- Android：使用 Chrome 打开部署地址，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。

PWA 安装需要 HTTPS 地址；本地 `http://127.0.0.1` 仅用于开发验证。

## Excel 导入

支持 `.xlsx`。必需列：

- `题目` 或 `题干`
- `答案`

建议列：

- `类型`：单选、多选、大题
- `选项A` 至 `选项H`
- `提示`：显示在直接答案下方的补充说明
- `解析`
- `标签`
- `难度`：基础、进阶、挑战

多选答案可写为 `A,C`、`AC` 或 `A、C`。应用内可下载标准模板。

## Word 导入

支持 `.docx`。推荐格式：

```text
1. 栈遵循什么原则？
A. 先进先出
B. 后进先出
答案：B
提示：回忆栈的插入和删除端。
解析：同一端插入和删除。
```

大题把参考答案写在 `答案：` 或 `参考答案：` 后。选择题答案可写为 `A,C` 或 `AC`。旧版 `.doc` 需要先在 Word 中另存为 `.docx`。

## PDF 导入

支持文字型 `.pdf`。导入器会读取章节标题、单选题、多选题、主观题和章节末尾的答案区，然后自动合并题目与答案。

PDF 必须满足：

- 文字可以复制，扫描图片 PDF 不支持。
- PDF 内包含答案区，或者使用名称中带“答案”“习题及答案”的完整题本。
- 一次导入一套 PDF 题库。

当前已用毛概“习题及答案”和习概“答案”PDF 验证，分别识别 340 道和 720 道题。

## 数据迁移

侧边栏的“导出数据备份”会生成 JSON 文件。其他设备打开同一页面后，在“导入题库”页面选择备份文件即可恢复。

恢复备份会覆盖当前浏览器中的题库和练习进度。

## 验证

```bash
npm test
npm run build
```

当前测试覆盖题型识别、答案清洗、选择题判分、大题自评、字段校验，以及 Excel、Word 导入解析。

## 目录

```text
src/
  components/        通用界面组件
  data/              初始示例题库
  lib/importers/     Excel、Word 解析
  lib/storage.ts     IndexedDB 持久化
```

## 已知边界

- 浏览器端只读取 `.xlsx` 和 `.docx`。
- Word 自动识别依赖题目序号、选项和答案字段。复杂排版仍需在导入预览阶段检查。
- 当前是本地方案，不提供账号、云端同步或多人共享。
